One step of attention, by hand

Three tokens: the · cat · sat. Each starts as a 4-number vector. Read the four slots as [determiner-ness, noun-ness, verb-ness, always-1] — in a real model nobody labels them; they come out of training.

tokenx (embedding)
the[2, 0, 0, 1]
cat[0, 2, 0, 1]
sat[0, 0, 2, 1]

Each token is projected three ways. Query = what I am looking for. Key = what I advertise. Value = what I hand over if you pick me. These are given to you already multiplied out:

tokenq (query)k (key)v (value)
the[0, 0, 0, 0][0, 2, 0, 1][2, 0, 0, 1]
cat[0, 0, 2, 0][0, 4, 0, 1][0, 2, 0, 1]
sat[0, 2, 0, 0][0, 0, 2, 1][0, 0, 2, 1]

We compute one row: what does "sat" attend to? Use q_sat = [0, 2, 0, 0].
