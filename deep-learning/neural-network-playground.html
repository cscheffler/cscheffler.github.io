Neural Network Playground

A network is a function with knobs. This page lets you turn every knob by hand and watch the function change. It is deliberately not a training demo — there is no gradient descent anywhere in it, because how the knobs get set is Session 2's job.

What it does

  • Mode 1 — one input, one output. Plots the function the network computes. You set every weight and bias with a slider, or by typing a number.
  • Mode 2 — two inputs, one output. The same network drawn as a heat map, with a labelled colour bar and contour lines.
  • Up to 3 hidden layers of up to 8 units each, including the zero-hidden-layer case (plain linear regression). The output unit is always linear.
  • Activations: sigmoid, ReLU, tanh, leaky ReLU, step, identity.
  • A clickable network diagram: edge colour shows the sign of a weight, edge thickness its magnitude, node fill the bias. Click an edge to jump to its slider.
  • Unit contributions (mode 1): each hidden unit's contribution to the output, drawn under the curve. Those plus the output bias sum exactly to the output — this is the picture that makes universal approximation click.
  • Target functions to match by hand, with a live RMSE readout, and a Difference view in mode 2 showing exactly where the network is wrong.
  • Presets for a few starting points. Two shapes are deliberately not provided — a 1-D bump and 2-D XOR — because building those by hand is the Session 1 exercise. Their targets are there, so you can check your attempt against the shape you are aiming for.
  • Save and Load a network as JSON, so a configuration can be prepared in advance and handed out.
  • Link gives you a URL carrying the whole page — architecture, every weight and bias, the target and the view toggles — so a particular setup can be handed out as a link. The address bar keeps itself up to date as you work. Your light/dark choice is not part of it: that stays with whoever opens the link.

Reading the colours

One convention throughout: warm is positive, cool is negative, and zero sits at the neutral midpoint. That holds for weight edges, bias node fills, and the heat map alike, so the colour bar beside the heat map also tells you how to read the diagram.

Sign never depends on colour alone. A negative weight is drawn dashed and a positive one solid, and on the heat map the level rings are dotted below zero and solid above it, so the sign of everything is readable without seeing colour at all. Magnitude is carried by line thickness in the diagram and by how far the fill sits from the neutral midpoint on the heat map — both of which also survive without colour. The selection highlight is plain ink rather than a fourth hue, for the same reason.

Suggested use in Session 1

The in-class warm-up asks “what does a second layer buy you?” Two demonstrations answer it directly:

  1. Set the activation to Identity. However many layers you stack, the output stays a straight line — non-linearity, not depth alone, is what buys expressiveness.
  2. Set the target to xor in mode 2 and try to match it by hand. With one hidden layer the best you can manage is a diagonal band; it takes a second layer to get the checkerboard. That is the exercise, and the failure with one layer is the point of it.

For the post-class exercise (design XOR by hand; sketch a bump from step functions), pick the matching target and build the network yourself — the live RMSE and, in mode 1, the unit-contribution overlay let you check a pen-and-paper answer against the picture. The Try this panel on the main page lists these prompts, so the page is usable without a facilitator narrating it.

Practical notes

  • The page is a single self-contained file. It needs no network access and no build step — open it in any modern browser, or hand out the file itself.
  • Your network, theme and settings are remembered in this browser between visits. The two modes keep separate networks, so switching between them loses nothing.
  • Everything is keyboard reachable; the diagram's nodes and edges are buttons.
